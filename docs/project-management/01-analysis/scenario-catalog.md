## SSH-01：查看主机基础信息

- **输入条件**：已建立 SSH 资产且可连接
- **目标资产**：Linux 主机
- **允许工具**：`system.info`
- **参数限制**：仅允许读取内核、发行版、架构、主机名和 uptime
- **必须证据**：系统信息快照、执行时间、退出状态
- **正常流程**：连接→采集→规范化→展示
- **失败流程**：连接失败返回 CONNECTION_FAILED
- **权限不足流程**：返回 POLICY_DENIED，不尝试替代命令
- **用户取消流程**：收到取消后终止并记录 CANCELLED
- **验收条件**：字段完整且无敏感环境变量
- **关联测试**：建议：internal/ssh/tools/system_info_test.go
- **当前实现状态**：`NOT_STARTED`

## SSH-02：判断系统负载是否异常

- **输入条件**：可读取 /proc 或系统命令输出
- **目标资产**：Linux 主机
- **允许工具**：`system.load, system.memory`
- **参数限制**：固定采样窗口≤10秒；不读取进程环境
- **必须证据**：load average、CPU 核数、内存/Swap
- **正常流程**：并行采集→计算利用率→解释
- **失败流程**：采样失败标记证据缺口
- **权限不足流程**：缺权限时展示可确认原因
- **用户取消流程**：取消采样并保留已完成证据
- **验收条件**：不凭单一 load 值下结论
- **关联测试**：建议：internal/ssh/tools/system_load_test.go
- **当前实现状态**：`NOT_STARTED`

## SSH-03：检查磁盘空间和 inode

- **输入条件**：目标主机在线
- **目标资产**：Linux 主机
- **允许工具**：`disk.usage`
- **参数限制**：仅固定命令模板；挂载点数≤200
- **必须证据**：文件系统、容量、已用、inode
- **正常流程**：采集→排序→阈值判断
- **失败流程**：解析失败返回 PARSE_FAILED
- **权限不足流程**：无权限挂载点单独标记
- **用户取消流程**：取消后停止解析和输出
- **验收条件**：能识别容量或 inode 高水位
- **关联测试**：建议：internal/ssh/tools/disk_usage_test.go
- **当前实现状态**：`NOT_STARTED`

## SSH-04：定位占用空间最大的目录/文件

- **输入条件**：用户指定允许路径
- **目标资产**：Linux 主机
- **允许工具**：`file.top_size`
- **参数限制**：路径必须在允许根目录；深度≤4；结果≤100
- **必须证据**：路径、大小、类型、扫描范围
- **正常流程**：校验路径→扫描→排序
- **失败流程**：超时返回 PARTIAL_RESULT
- **权限不足流程**：越界路径 POLICY_DENIED
- **用户取消流程**：取消终止远程进程
- **验收条件**：不能扫描 / 等未授权根路径
- **关联测试**：建议：internal/ssh/tools/file_top_size_test.go
- **当前实现状态**：`NOT_STARTED`

## SSH-05：查看服务状态与最近失败原因

- **输入条件**：用户指定 systemd unit
- **目标资产**：Linux 主机
- **允许工具**：`service.status, log.tail`
- **参数限制**：unit 名字白名单格式；日志≤500行
- **必须证据**：active/sub、退出码、最近日志
- **正常流程**：状态→日志→关联时间
- **失败流程**：非 systemd 返回 UNSUPPORTED
- **权限不足流程**：journal 权限不足单独报告
- **用户取消流程**：取消日志读取
- **验收条件**：不执行 restart/stop/start
- **关联测试**：建议：internal/ssh/tools/service_status_test.go
- **当前实现状态**：`NOT_STARTED`

## SSH-06：查看高 CPU/内存进程

- **输入条件**：主机在线
- **目标资产**：Linux 主机
- **允许工具**：`process.list`
- **参数限制**：结果≤100；不读取 cmdline 中秘密参数原文
- **必须证据**：PID、用户、CPU、内存、脱敏命令
- **正常流程**：采样→排序→脱敏
- **失败流程**：进程消失允许部分结果
- **权限不足流程**：/proc 权限不足标记
- **用户取消流程**：取消采样
- **验收条件**：敏感参数被替换
- **关联测试**：建议：internal/ssh/tools/process_list_test.go
- **当前实现状态**：`NOT_STARTED`

## SSH-07：确认端口是否监听及对应进程

- **输入条件**：用户提供端口或范围
- **目标资产**：Linux 主机
- **允许工具**：`network.listen`
- **参数限制**：端口1–65535；最多20个端口
- **必须证据**：地址、端口、协议、PID/进程
- **正常流程**：校验→查询→关联进程
- **失败流程**：工具不可用返回 UNSUPPORTED
- **权限不足流程**：关联 PID 权限不足不扩大权限
- **用户取消流程**：取消查询
- **验收条件**：不主动扫描远程网络
- **关联测试**：建议：internal/ssh/tools/network_listen_test.go
- **当前实现状态**：`NOT_STARTED`

## SSH-09：按时间和关键字搜索日志

- **用户取消流程**：取消远程搜索
- **验收条件**：不允许正则灾难性表达式
- **关联测试**：建议：internal/ssh/tools/log_search_test.go

## SSH-10：检查系统时间、时区和同步状态

- **用户取消流程**：取消采集
- **验收条件**：不执行 timedatectl set-*

## DB-01：验证数据库连接和基本信息

- **输入条件**：已配置 MySQL/PostgreSQL 资产
- **目标资产**：数据库
- **允许工具**：`db.connection_stats`
- **参数限制**：连接超时≤10秒；不暴露 DSN
- **必须证据**：版本、当前库、只读状态、延迟
- **正常流程**：连接→查询固定元数据→断开/归还池
- **失败流程**：连接失败分类认证/网络/TLS
- **权限不足流程**：权限不足返回 DB_PERMISSION_DENIED
- **用户取消流程**：取消连接
- **验收条件**：凭据不进入结果
- **关联测试**：建议：internal/database/tools/connection_stats_test.go
- **当前实现状态**：`NOT_STARTED`

## DB-02：列出 Schema 和表

- **输入条件**：数据库可连接
- **目标资产**：数据库
- **允许工具**：`db.schemas, db.tables`
- **参数限制**：最多1000对象；限定当前资产
- **必须证据**：名称、类型、估算行数
- **正常流程**：Schema→Table→分页
- **失败流程**：元数据查询失败明确方言
- **权限不足流程**：不可见对象不绕过权限
- **用户取消流程**：取消分页
- **验收条件**：支持 MySQL/PostgreSQL 差异
- **关联测试**：建议：internal/database/tools/schema_test.go
- **当前实现状态**：`NOT_STARTED`

## DB-05：分析一条慢 SELECT

- **输入条件**：用户提供 SELECT
- **目标资产**：数据库
- **允许工具**：`db.explain`
- **参数限制**：仅单条 SELECT/WITH；禁止执行 ANALYZE 默认；超时≤30秒
- **必须证据**：规范化 SQL hash、计划、成本
- **正常流程**：解析→只读校验→EXPLAIN→解释
- **失败流程**：解析失败不发送数据库
- **权限不足流程**：无 EXPLAIN 权限返回原因
- **用户取消流程**：取消数据库请求
- **验收条件**：禁止 DML/DDL/多语句
- **关联测试**：建议：internal/database/tools/explain_test.go
- **当前实现状态**：`NOT_STARTED`

## DB-10：执行受限只读业务查询

- **输入条件**：用户确认 SQL 和范围
- **目标资产**：数据库
- **允许工具**：`db.query_readonly`
- **参数限制**：仅 SELECT/WITH；只读事务；≤1000行；≤10MB；≤30秒
- **必须证据**：列、行、耗时、截断、SQL hash
- **正常流程**：解析→风险重算→只读事务→限流→脱敏
- **失败流程**：超时回滚并返回 DB_TIMEOUT
- **权限不足流程**：权限不足原样分类
- **用户取消流程**：取消请求并回滚
- **验收条件**：任何写语句必须在客户端解析和数据库层双重拒绝
- **关联测试**：建议：internal/database/tools/query_readonly_test.go
- **当前实现状态**：`NOT_STARTED`

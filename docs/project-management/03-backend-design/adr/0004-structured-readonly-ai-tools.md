# ADR 0004：AI 仅使用结构化只读工具

- **日期**：2026-07-11
- **状态**：Accepted

## 背景

任意 Shell/SQL 黑名单难以覆盖组合、方言和提示注入。

## 决策

模型仅选择版本化 ToolDefinition 并填写受限参数；禁止任意命令和 DML/DDL。

## 备选方案

- 维持临时实现并后补边界。
- 使用另一套桌面/执行架构。
- 将能力交给云端服务。

以上方案因安全边界、单人维护或本地优先目标不符合而未选择。

## 影响

能力范围较窄，但安全性、可测试性和结果稳定性更高。

## 验证

通过对应 Backlog、架构测试和 Beta 门禁验证；若事实推翻决策，创建新 ADR supersede 本记录。
